# Configuration

All configuration is supplied through environment variables. Copy `.env.example` to `.env` for local development.

## LiveKit server

| Variable                  | Required | Description                                                                                                                                                                                                        |
| ------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `LIVEKIT_API_KEY`         | yes      | API key for the LiveKit server.                                                                                                                                                                                    |
| `LIVEKIT_API_SECRET`      | yes      | API secret for the LiveKit server.                                                                                                                                                                                 |
| `LIVEKIT_URL`             | yes      | Server SDK URL, e.g. `wss://my-project.livekit.cloud` or `ws://livekit:7880` in Docker. The server SDK normalizes this to `https://...` internally.                                                                |
| `NEXT_PUBLIC_LIVEKIT_URL` | no       | Browser-facing URL. Defaults to `LIVEKIT_URL`. Use this when the server SDK needs an internal address (e.g. a Docker hostname) but browsers must connect to a host-routable address such as `ws://localhost:7880`. |

## Encryption

| Variable      | Required | Description                                                                                          |
| ------------- | -------- | ---------------------------------------------------------------------------------------------------- |
| `E2EE_SECRET` | yes      | Secret used to derive the default per-room E2EE passphrase. Generate with `openssl rand -base64 32`. |

## Authentication

| Variable             | Required | Description                                                                                                                   |
| -------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `OIDC_ISSUER`        | yes      | Base URL of the OIDC provider. The discovery document must be available at `${OIDC_ISSUER}/.well-known/openid-configuration`. |
| `OIDC_CLIENT_ID`     | yes      | OAuth2 client ID.                                                                                                             |
| `OIDC_CLIENT_SECRET` | yes      | OAuth2 client secret.                                                                                                         |
| `AUTH_SECRET`        | yes      | NextAuth secret used to encrypt session cookies. Generate with `openssl rand -base64 32`.                                     |
| `AUTH_TRUST_HOST`    | no       | Set to `true` in containerized or local environments so NextAuth trusts the host header.                                      |
| `AUTH_URL`           | no       | Public URL of the deployment, e.g. `https://meet.sunbeam.pt`.                                                                 |
| `ALLOW_TEST_AUTH`    | no       | Enables a credentials test provider for Playwright. Never enable this in production.                                          |

## Database

| Variable       | Required | Description                                                                          |
| -------------- | -------- | ------------------------------------------------------------------------------------ |
| `DATABASE_URL` | yes      | Postgres connection string, e.g. `postgres://user:pass@localhost:5432/livekit_meet`. |

## Meeting links

| Variable        | Required | Description                                                                                      |
| --------------- | -------- | ------------------------------------------------------------------------------------------------ |
| `MEET_BASE_URL` | yes      | Base URL used for meeting links generated by the Bulwark plugin, e.g. `https://meet.sunbeam.pt`. |

## Optional features

| Variable                            | Required | Description                                                                                                    |
| ----------------------------------- | -------- | -------------------------------------------------------------------------------------------------------------- |
| `NEXT_PUBLIC_SHOW_SETTINGS_MENU`    | no       | Set to `true` to enable the in-call settings menu, including the recording tab. Must be present at build time. |
| `NEXT_PUBLIC_CONN_DETAILS_ENDPOINT` | no       | Override the connection-details endpoint. Defaults to `/api/connection-details`.                               |

## Recording (S3 egress)

Recording is opt-in and requires S3-compatible storage:

| Variable        | Required | Description                 |
| --------------- | -------- | --------------------------- |
| `S3_KEY_ID`     | yes      | S3 access key ID.           |
| `S3_KEY_SECRET` | yes      | S3 secret access key.       |
| `S3_ENDPOINT`   | yes      | S3-compatible endpoint URL. |
| `S3_BUCKET`     | yes      | Bucket name for recordings. |
| `S3_REGION`     | yes      | S3 region.                  |

## Observability

| Variable                           | Required | Description                        |
| ---------------------------------- | -------- | ---------------------------------- |
| `NEXT_PUBLIC_DATADOG_CLIENT_TOKEN` | no       | Enables Datadog browser logs.      |
| `NEXT_PUBLIC_DATADOG_SITE`         | no       | Datadog site, e.g. `datadoghq.eu`. |

## Bulwark integration

| Variable                 | Required | Description                                                        |
| ------------------------ | -------- | ------------------------------------------------------------------ |
| `BULWARK_WEBHOOK_URL`    | no       | URL where LiveKit lifecycle webhooks are forwarded to Bulwark.     |
| `BULWARK_WEBHOOK_SECRET` | no       | Shared secret used to sign Bulwark webhook payloads (HMAC-SHA256). |
